New project page checklist

Copy /projects/ttvr.html as a starting point (or neil.html for a page with no real video yet), then:
  1. Update <title>
  2. Keep both <div data-include> placeholders and the /assets/notebook.css + /assets/include.js links
  3. h1 + .project-meta tape-labels (category · studio · project type)
  4. .screen (margin-top:24px) + .reel-card for the main video or a placeholder still image
  5. .prose for the description, .credit-card for your role
  6. Add a card to index.html's .grid: <a class="card" data-cat="..." href="/projects/your-file.html">
